# OKONSKI Performance Protocol Library

Next.js App Router prototype for the internal OKONSKI protocol library.

## Run locally

```bash
npm install
npm run dev
```

Then open: http://localhost:3000

## Routes

- `/` — Shoulder master protocol
- `/exercises` — Exercise library

## Brand system

- Deep Charcoal Black `#0A0B0D`
- Dark Steel Grey `#1E2229`
- Premium Steel Blue `#3E6FA8`
- Off-White / Silver `#E2E8F0`

The files under `public/assets` use the actual OKONSKI brand assets supplied for the project.
